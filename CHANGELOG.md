# История изменений

## [0.9.3] - TBD

### Исправлено
- 🎯 **Кнопки в статусе заданий** - Исправлена проблема с кнопками скачивания и удаления, которые не помещались в рамку при длинных именах файлов
- 📝 **Логи при обновлении** - Исправлена проблема с отсутствием первых записей логов при обновлении страницы или входе во время кодирования
- 🎛️ **Выбор пресетов** - Исправлена проблема с пресетами, когда всегда прописывался пользовательский вместо выбранного из списка
- 🔧 **Логика определения кастомности** - Улучшена логика сравнения параметров пресета с пользовательскими настройками
- ⚡ **Настройки производительности** - Исправлена проблема с передачей настроек производительности в команду FFmpeg
- 🎬 **Пресеты с null значениями** - Исправлена обработка пресетов с null значениями (например, "Только видео" без аудио)
- 🔍 **Отладка пресетов** - Добавлено детальное логирование для отладки проблем с определением кастомности пресетов
- 📊 **FFmpeg логи** - Улучшена обработка FFmpeg логов при загрузке существующих записей
- ⚡ **Ограничения x265** - Исправлена ошибка с превышением максимального количества frame-threads в x265 (максимум 16)
- 🔧 **Оптимизация потоков** - Добавлены разумные ограничения на количество потоков CPU (максимум 64) и x265 pools (максимум 32)

### Добавлено
- 📊 **API для логов** - Добавлен API endpoint `/api/logs` для получения существующих логов из файлов
- 🔄 **Автозагрузка логов** - Добавлена автоматическая загрузка существующих логов при инициализации страницы логов
- ⚡ **Автоопределение потоков** - Добавлено автоматическое определение максимального количества потоков CPU при старте приложения
- 📁 **Внутренний режим кодирования** - Можно взять файл с примонтированного хранилища (`POST /api/internal/encode`) вместо загрузки с устройства; в UI переключатель «С устройства» / «С хранилища»

### Изменено
- 📝 **Примечание о потоках** - Изменено примечание о настройках потоков: убрано упоминание Apple M2 Pro, добавлено общее объяснение про значение 0
- 🎨 **Структура карточек** - Улучшена структура HTML для карточек заданий с лучшей обработкой длинных имен файлов
- 🔍 **Сравнение параметров** - Оптимизирована логика сравнения параметров пресета с пользовательскими настройками
- 🐍 **Версия Python в документации** - README приведён к фактическому runtime в Docker (`python:3.14-slim`)

### Технические изменения
- **CSS**: Добавлены стили для корректного отображения кнопок в карточках заданий
- **JavaScript**: Улучшена структура HTML элементов с использованием `text-truncate` и `title` атрибутов
- **Backend**: Добавлен новый API endpoint для получения логов из файлов
- **Frontend**: Добавлена функция `loadExistingLogs()` для загрузки существующих логов
- **Логика**: Улучшена функция `get_ffmpeg_params_from_request()` для более точного определения кастомности
- **FFmpeg Worker**: Исправлена логика определения количества потоков CPU и x265 pools
- **Пресеты**: Улучшена обработка null значений в пресетах для корректного отображения названий
- **Отладка**: Добавлено детальное логирование в backend и console.log в frontend для отладки пресетов
- **API логов**: Улучшена обработка FFmpeg логов с специальной обработкой прогресс строк
- **FFmpeg Worker**: Добавлены ограничения на количество потоков для предотвращения ошибок x265
- **x265 параметры**: Исправлена логика установки frame-threads с учетом ограничений x265
- **Python 3.15 prep**: явное `encoding='utf-8'` при чтении `build_number.txt` (PEP 686)
- **Typing**: `Optional`/`Dict`/`List`/`Tuple` заменены на `X | None` и встроенные generics (`dict`/`list`/`tuple`)

## [0.9.2] - 2025-10-22

### Добавлено
- 🎯 **Отображение пресета в прогресс-барах** - Под каждым прогресс-баром кодирования отображается используемый пресет
- 🔧 **Умное определение типа пресета** - Система автоматически определяет "Пользовательский" если пресет был изменен
- 📊 **Кеширование пресетов** - Глобальный кеш `window.presetsCache` для быстрого получения названий пресетов
- 🎨 **Иконка пресета** - Добавлена иконка шестеренки (🔧) для визуального выделения информации о пресете

### Улучшено
- 🎛️ **Система пресетов** - Backend теперь сравнивает все параметры формы с параметрами пресета для определения кастомности
- 📱 **UI/UX** - Информация о пресете отображается на всех страницах (главная, логи) для консистентности
- 🔍 **Прозрачность** - Пользователь всегда видит, какой пресет используется и были ли внесены изменения
- ⚡ **Производительность** - Кеширование названий пресетов исключает повторные API запросы

### Исправлено
- 🐛 **Обработка кастомных пресетов** - Исправлена логика определения модифицированных пользователем пресетов
- 🔄 **Синхронизация данных** - Улучшена передача `preset_id` между frontend и backend
- 📝 **Отображение информации** - Исправлено отображение названий пресетов в различных состояниях заданий

### Технические изменения
- **Backend**: 
  - Функция `get_ffmpeg_params_from_request()` теперь возвращает `(params, preset_id)`
  - Добавлена логика сравнения параметров формы с параметрами пресета
  - Все функции создания заданий обновлены для передачи `preset_id`
- **Frontend**:
  - Добавлена функция `getPresetDisplayName()` для определения названия пресета
  - Обновлена функция `createJobElement()` для отображения информации о пресете
  - Добавлен глобальный кеш `window.presetsCache` для хранения названий пресетов
- **UI**:
  - Под прогресс-барами добавлен блок с информацией о пресете
  - Стилизация: `text-muted small mt-1` с иконкой шестеренки

## [0.8.0] - 2025-10-20

### Добавлено
- 🎬 Базовая система кодирования видео
- 📁 Поддержка загрузки одиночных файлов и ZIP архивов
- ⚙️ Полная настройка параметров FFmpeg через веб-интерфейс
- 🔄 Real-time обновления прогресса через WebSocket
- 📊 Дашборд с мониторингом заданий
- 📝 Система логирования в реальном времени
- 🐳 Полная контейнеризация с Docker
- 🎨 Современный UI с Bootstrap 5
- 🔧 Автоматическая очистка исходных файлов
- 📱 Адаптивный дизайн для мобильных устройств

### Технические особенности
- Python 3.13 + Flask + Flask-SocketIO
- FFmpeg для кодирования видео
- Bootstrap 5 для фронтенда
- Docker + Docker Compose для развертывания
- WebSocket для real-time обновлений
- Валидация файлов по хешу
- Поддержка H.265/HEVC кодирования

### Поддерживаемые форматы
- **Входные**: .mp4, .mkv, .zip
- **Выходные**: .mkv (Matroska)

### Параметры FFmpeg
- Карты потоков (видео, аудио, субтитры, данные)
- Кодеки (H.265, H.264, AAC, MP3, FLAC)
- Скорость кодирования (от ультра быстро до очень медленно)
- Качество (CRF от 0 до 51)
- Форматы пикселей (8-bit, 10-bit)
- Оптимизация (анимация, фильм, зерно и др.)

### Статусы заданий
- Запланировано (серый)
- Выполняется (желтый)
- Готово (зеленый)
- Ошибка (красный)

### Действия с заданиями
- Скачивание готовых файлов
- Остановка выполнения
- Удаление заданий и файлов

### Мониторинг
- Real-time прогресс кодирования
- Live логи FFmpeg
- Статистика заданий
- Проверка здоровья системы

### Безопасность
- Валидация типов файлов
- Проверка целостности по хешу
- Ограничение размера файлов (16GB)
- Автоматическая очистка временных файлов

### Производительность
- Многопоточная обработка
- Эффективное использование ресурсов
- Оптимизированные Docker образы
- Настраиваемые лимиты памяти и CPU

### Документация
- Подробный README
- Быстрый старт
- Примеры использования
- Makefile для удобства
- Конфигурационные файлы
