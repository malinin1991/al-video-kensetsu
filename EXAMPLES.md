# Примеры использования

## Базовое кодирование

1. **Загрузите видео файл** (.mp4 или .mkv)
2. **Оставьте параметры по умолчанию** для оптимального качества
3. **Нажмите "Загрузить"**
4. **Дождитесь завершения** кодирования
5. **Скачайте готовый файл**

## Настройка параметров

### Для высокого качества (медленно)
- **Скорость кодирования**: Очень медленно
- **Качество (CRF)**: 18
- **Формат пикселей**: 10-bit (yuv420p10le)

### Для быстрого кодирования
- **Скорость кодирования**: Быстро
- **Качество (CRF)**: 28
- **Формат пикселей**: 8-bit (yuv420p)

### Для анимации
- **Оптимизация**: Анимация
- **Скорость кодирования**: Медленно
- **Качество (CRF)**: 20

### Для живого видео / зерна плёнки
- **Оптимизация**: grain (или none)
- **Скорость кодирования**: Медленно
- **Качество (CRF)**: 23

## Пакетная обработка

1. **Выберите несколько файлов** `.mp4` / `.mkv` в поле загрузки
2. **Выберите пресеты видео и аудио** для всей пачки
3. **Нажмите «Загрузить»**
4. **Система создаст отдельные задания** для каждого видео
5. **Следите за прогрессом** всех заданий одновременно

Лимит параллельности задаётся на странице «Настройки»; по умолчанию кодируется
одно задание. Готовые результаты можно выбрать и скачать одним ZIP архивом.
Пакетный запуск с хранилища через `paths` описан в [docs/API.md](docs/API.md).

## Мониторинг заданий

### Статусы заданий
- **Запланировано** (серый) - задание в очереди
- **Выполняется** (желтый) - кодирование в процессе
- **Готово** (зеленый) - файл готов к скачиванию
- **Ошибка** (красный) - произошла ошибка
- **Отменено** - задание остановлено пользователем

### Действия с заданиями
- **Скачать** - загрузить готовый файл
- **Остановить** - прервать выполнение
- **Удалить** - удалить задание и файлы

## Логи и отладка

1. **Перейдите на страницу "Логи"**
2. **Просматривайте** real-time логи FFmpeg
3. **Проверяйте** статус всех заданий
4. **Анализируйте** ошибки при необходимости

## Рекомендации по производительности

### Для больших файлов
- Используйте **SSD накопитель**
- Увеличьте **лимит памяти Docker**
- Выберите **быструю скорость кодирования**

### Для лучшего качества
- Используйте **медленную скорость кодирования**
- Установите **низкое значение CRF** (18-20)
- Выберите **10-bit формат пикселей**

### Для экономии места
- Установите **высокое значение CRF** (28-30)
- Используйте **быструю скорость кодирования**
- Выберите **8-bit формат пикселей**
