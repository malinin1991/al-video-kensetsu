# Быстрый старт

## Запуск системы

### Вариант 1: Автоматический запуск
```bash
./run.py
```

### Вариант 2: Ручной запуск
```bash
docker-compose up --build
```

## Использование

1. Откройте браузер и перейдите по адресу: http://localhost:3000
2. Выберите видео файл (.mp4, .mkv) или ZIP архив с видео файлами
3. Настройте параметры кодирования FFmpeg
4. Нажмите "Загрузить"
5. Следите за прогрессом в реальном времени
6. Скачайте готовый файл после завершения кодирования

## Остановка системы

Нажмите `Ctrl+C` в терминале или выполните:
```bash
docker-compose down
```

## Структура файлов

- `uploads/` - загруженные файлы
- `outputs/` - закодированные файлы
- `logs/` - логи системы

## Поддерживаемые форматы

- **Входные**: .mp4, .mkv, .zip (с видео файлами)
- **Выходные**: .mkv (Matroska)

## Требования

- Docker и Docker Compose
- 4 GB RAM (рекомендуется 8 GB)
- 10 GB свободного места (рекомендуется 50 GB)
