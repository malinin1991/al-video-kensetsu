Обновление метаданных
Подмена базового имени видеодорожки для текущего пака файлов (релизная группа → Original и т.п.). Действует при одной video-дорожке в файле. Часть в хвостовых [] сохраняется; ник дописывается отдельно. Пустое имя в файле уже считается Original. Не сохраняется между сессиями (в отличие от ника).
Для видео смотрим только на хвостовую внешнюю пару [] (содержимое внутри сохраняется как есть, вложенность не разбираем): без скобок — Title [Nick] (и Original, и AniLiberty, и любое другое имя); со скобками — вклеиваем в начало тега: Title [Nick + …]. Для аудио «Original»/«Оригинал» — простой суффикс при перекодировании аудио (без merge). Сохраняется в томе settings (/app/settings/app_settings.json) и переживает перезапуск. Структурные символы ника (\, [, ], +) при записи в тег экранируются; пустой ник тоже можно сохранить.
Правила: глобальные и служебные теги FFmpeg удаляются; заголовок контейнера (mkvmerge --title) очищается; единственное видео — default + forced; пустое имя видеодорожки → «Original»; видео «Original»/«Оригинал» — original-flag; аудио «AniLiberty» — default + forced (язык ru); пустое имя default-аудио → «AniLiberty»; пустое имя non-default аудио → «Original»; аудио «Original»/«Оригинал» — язык оригинала и original-flag (при перекодировании аудио — суффикс ника); субтитры: default → «Надписи» (default + forced), иначе → «Субтитры»; если субтитров нет — запись в системный лог.
